# QuizMaster Pro

An interactive trivia quiz bot with built-in questions.

## Features
- Multiple categories
- Difficulty levels
- Score tracking

## Setup

```bash
git clone <repository-url>
cd quizmaster-pro
pip install -r requirements.txt
python app.py
```

## Docker

```bash
docker build -t quizmaster-pro .
docker run -p 3000:3000 quizmaster-pro
```
